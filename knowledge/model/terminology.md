# Terminology

| Term | Controlled meaning |
|---|---|
| ATS | Recruiting record/workflow system; does not imply automated ranking. |
| Resume parsing | Extraction of text/fields from a resume. |
| Structured application data | Candidate-supplied or derived values stored in defined fields. |
| Screening question | Employer-authored question used for information or evaluation. |
| Knockout/disqualifier | Configured answer/threshold that can end consideration. |
| Search/filter | User-directed retrieval or narrowing; not an adverse decision by itself. |
| Match | Comparison between evidence and role criteria; scope must be stated. |
| Rank/prioritise | Order/group records for review; not synonymous with final decision. |
| Scorecard | Structured human feedback form unless explicitly identified as another mechanism. |
| Disposition | Recorded reason/status for ending or changing consideration. |
| Optional | Requires entitlement, add-on, enablement or feature availability. |
| Configurable | Customer choices determine whether/how a native mechanism acts. |
| Third-party | External provider supplies material behavior or result. |
| Platform-informed screening simulation | Evidence-based scenarios informed by public platform capabilities; not the platform algorithm. |
| Evidence-based application readiness assessment | Candidate-facing analysis of parseability, eligibility and job evidence without claiming employer outcome. |
| Missing evidence | Relevant evidence not observed; not proof the candidate lacks the capability. |
| Culture fit | Prohibited scoring concept. Use observable role-related competencies instead. |

## Platform-specific terms

- **Greenhouse:** Application Review; interview plan; rejection reason; Real Talent; Talent Matching.
- **Lever:** candidate profile; opportunity; archive/archive reason; Fast Resume Review; Talent Fit.
- **Workday:** Job Application business process; subprocess; Move Forward; Decline; disposition; Ready for Hire; Candidate Skills Match; HiredScore.
- **SAP SuccessFactors:** Candidate Profile; application; prescreening question; Applicant Workbench; applicant status; Skill Compatibility.
